# ตำราหมอดู.com: รวมทุกศาสตร์

ตำราค่าเริ่มต้นทั้งหมดที่ใช้ในระบบ ดึงจากโค้ดจริง (`lib/calc/kb.js` และ `lib/calc/data/`) เมื่อ 2026-11-23

**สถานะ:** ทุกตารางยังเป็น "ร่าง" รอผู้รู้ตรวจ แก้ได้ที่หลังบ้าน (📜 ตำราดูดวง) ซึ่งเก็บประวัติ 20 เวอร์ชันและมีปุ่มคืนค่าเริ่มต้น ส่วนที่บันทึกในหลังบ้านจะทับค่าในไฟล์นี้

**วิธีใช้กับ Claude Code:** แก้ข้อความในตารางของไฟล์นี้ แล้วสั่งให้อัปเดตไฟล์ต้นทางตามที่ระบุในแต่ละหัวข้อ คอลัมน์ที่เขียนว่า "ล็อก" ห้ามแก้ เพราะผลคำนวณจะเพี้ยน

## สารบัญ
1. คู่เลข (เบอร์โทร ทะเบียน บ้านเลขที่)
2. สีและอักษรประจำดาว (ทักษา · กาลกิณี)
3. ค่าตัวอักษรเลขศาสตร์
4. อี้จิง 64 ฉบับ
5. มหาโบตะ 7 เรือน
6. ฮวงจุ้ย: ความหมาย 8 ทิศ
7. ฮวงจุ้ย: ดาวเหิน 9 ดวง
8. ตำราลายมือ
9. สูตรคำนวณที่ล็อกไว้ในโค้ด (ไม่อยู่ในหลังบ้าน)

## 8. ตำราลายมือ
ต้นทาง: `lib/calc/data/palm-data.js` (PALM_DATA) · ส่งให้ AI ทุกครั้งที่อ่านรูปลายมือ/ข้อมือ (ผ่าน `api/_lib/palm-guide.js`) · ไม่เกิน 12,000 ตัวอักษร · ต้องคงข้อห้ามเรื่องสุขภาพและอายุขัยไว้

```text
ตำราลายมือของหมอดู.com (ใช้เป็นหลักในการอ่าน · อ่านเฉพาะสิ่งที่เห็นในรูปจริง):

【รูปทรงมือ】
- มือเหลี่ยม (ฝ่ามือเหลี่ยม นิ้วปลายตัด): มีระเบียบ ทำงานเป็นขั้นตอน เชื่อถือได้ ชอบความชัดเจน
- มือปลายนิ้วแบน/บานออก (spatulate): กระตือรือร้น ชอบลงมือ ชอบสิ่งใหม่และการเคลื่อนไหว
- มือข้อนิ้วเด่น (philosophic): ช่างคิด ชอบวิเคราะห์ หาเหตุผลก่อนเชื่อ
- มือเรียวปลายนิ้วมน (conic): อารมณ์ศิลปิน ใช้ความรู้สึกนำ ปรับตัวเก่ง
- มือเรียวยาวปลายแหลม (psychic): อ่อนไหว จินตนาการสูง ใส่ใจความงาม
- มือผสม: ปรับตัวได้หลายบทบาท ความสามารถหลากหลาย
- มือนุ่มมาก = รักความสบาย · มือแน่นยืดหยุ่น = มีพลังและความรับผิดชอบ

【นิ้วและนิ้วโป้ง】
- นิ้วโป้งยาวและแข็งแรง = มีความตั้งใจและควบคุมตนเองได้ · นิ้วโป้งสั้น = ใช้อารมณ์นำมากกว่าเหตุผล
- ข้อบนของนิ้วโป้ง = ความตั้งใจ · ข้อล่าง = เหตุผลและการวางแผน
- นิ้วชี้ (ดาวพฤหัส): ยาว = ความเป็นผู้นำ ความทะเยอทะยาน
- นิ้วกลาง (ดาวเสาร์): ยาวตรง = รอบคอบ จริงจัง มีความรับผิดชอบ
- นิ้วนาง (ดาวอาทิตย์): ยาว = รักศิลปะ ชื่อเสียง กล้าแสดงออก
- นิ้วก้อย (ดาวพุธ): ยาว = สื่อสารเก่ง ค้าขาย เจรจา

【เนิน】(นูนเด่น = พลังด้านนั้นมาก · แบนราบ = พลังด้านนั้นน้อย)
- ใต้นิ้วชี้ (พฤหัส): ความทะเยอทะยาน ศักดิ์ศรี
- ใต้นิ้วกลาง (เสาร์): ความรอบคอบ ชอบความสันโดษ
- ใต้นิ้วนาง (อาทิตย์): ความสำเร็จ ศิลปะ ชื่อเสียง
- ใต้นิ้วก้อย (พุธ): การพูด การค้า ไหวพริบ
- ฐานนิ้วโป้ง (ศุกร์): ความรัก ความอบอุ่น พลังชีวิต
- ขอบมือฝั่งตรงข้ามนิ้วโป้ง (จันทร์): จินตนาการ ความฝัน การเดินทาง
- กลางฝ่ามือ/ขอบเนินอังคาร: ความกล้า ความอดทนต่อแรงกดดัน

【เส้นหลัก】
- เส้นชีวิต (โค้งรอบฐานนิ้วโป้ง): บอกพลังและความกระตือรือร้นในการใช้ชีวิต โค้งกว้าง = กระตือรือร้น ชอบเข้าสังคม · โค้งแคบ = ระมัดระวัง เก็บตัว · ห้ามใช้ทำนายอายุขัย
- เส้นสมอง (กลางฝ่ามือ): ตรงยาว = คิดเป็นระบบ ใช้เหตุผล · โค้งลงเนินจันทร์ = จินตนาการ สร้างสรรค์ · เริ่มติดเส้นชีวิต = รอบคอบก่อนตัดสินใจ · แยกจากเส้นชีวิต = กล้าคิดกล้าทำ เป็นตัวของตัวเอง
- เส้นหัวใจ (บนสุด ใต้ฐานนิ้ว): ยาวไปใต้นิ้วชี้ = รักอย่างมีอุดมคติ เลือกคู่ · จบใต้นิ้วกลาง = รักแบบจริงจังแต่ไม่หวานแสดงออก · โค้งขึ้น = แสดงความรู้สึกเปิดเผย · ตรง = เก็บความรู้สึก
- เส้นวาสนา/ชะตา (แนวตั้งกลางฝ่ามือขึ้นไปทางนิ้วกลาง): ชัดตลอด = เส้นทางชีวิตชัดเจน · เริ่มจากเนินจันทร์ = ได้รับแรงหนุนจากผู้อื่น · เริ่มจากเส้นชีวิต = สร้างตัวด้วยตนเอง · ไม่มีเส้นนี้ = ชีวิตยืดหยุ่น ไม่ได้แปลว่าไม่มีวาสนา
- เส้นอาทิตย์ (แนวตั้งขึ้นไปทางนิ้วนาง): ความสำเร็จ ชื่อเสียง ความพอใจในชีวิต
- เส้นพุธ (แนวเฉียงไปทางนิ้วก้อย): ไหวพริบทางธุรกิจและการสื่อสาร (ห้ามใช้วินิจฉัยสุขภาพ)
- เส้นความสัมพันธ์ (เส้นสั้นแนวนอนขอบมือใต้นิ้วก้อย): ความผูกพันที่สำคัญในชีวิต อ่านเป็นแนวโน้มเท่านั้น ห้ามระบุจำนวนคู่หรือวันแต่ง

【เส้นข้อมือ (สร้อยข้อมือ)】
- เส้นชัดต่อเนื่อง 2–3 เส้น = พื้นฐานชีวิตมั่นคง · เส้นแรกโค้งขึ้นไปในฝ่ามือ = ควรดูแลการพักผ่อนและสมดุลชีวิต (คำแนะนำทั่วไป ไม่ใช่การวินิจฉัย)

【เครื่องหมาย】
- ดาว (✳) บนเนิน = โอกาสโดดเด่นในด้านของเนินนั้น · กากบาท = จุดตัดสินใจสำคัญ · เกาะ (วงรีบนเส้น) = ช่วงที่พลังด้านนั้นสะดุดชั่วคราว
- สี่เหลี่ยมล้อมเส้น = เครื่องหมายคุ้มครอง ผ่านพ้นได้ · สามเหลี่ยม = สติปัญญาและความชำนาญ · ตาราง/ร่างแห = พลังกระจัดกระจาย ควรโฟกัส
- เส้นขาดแล้วมีเส้นใหม่ซ้อน = การเปลี่ยนแปลงทิศทางที่มีทางต่อ

【มือซ้าย/ขวา】มือที่ไม่ถนัด = พื้นฐานที่ติดตัวมา · มือที่ถนัด = สิ่งที่สร้างขึ้นเอง ถ้าต่างกันให้เล่าว่าเปลี่ยนแปลงไปทางไหน

ข้อห้ามเพิ่มเติม: ไม่ทำนายอายุขัย ความตาย อุบัติเหตุร้ายแรง หรือโรคจากลายมือ · ไม่ระบุจำนวนลูกหรือจำนวนคู่ · ถ้าเห็นไม่ชัดให้บอกตรง ๆ
```
